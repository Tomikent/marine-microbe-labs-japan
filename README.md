# Marine Microbiology Labs Japan

日本国内の海洋微生物の研究室（関連分野含む）を、地図と一覧から探せるリンク集です。
個人が作成・運営している非公式のものです。

**サイト：https://tomikent.github.io/marine-microbe-labs-japan/**

> [!TIP]
> **載っていない研究室や情報の誤りを見つけたら、フォームから教えてください（アカウント不要）**
>
> [![研究室の追加・修正・取り下げ](https://img.shields.io/badge/%E7%A0%94%E7%A9%B6%E5%AE%A4%E3%81%AE%E8%BF%BD%E5%8A%A0%E3%83%BB%E4%BF%AE%E6%AD%A3%E3%83%BB%E5%8F%96%E3%82%8A%E4%B8%8B%E3%81%92-2ea44f?style=for-the-badge)](https://docs.google.com/forms/d/e/1FAIpQLScZexKD9ZMVBIU6HGvxZvkAmbIja_D99QdabPEnDhZZvvbTkg/viewform)
>
> GitHub アカウントがある人は [Issue（研究室の追加・修正）](https://github.com/Tomikent/marine-microbe-labs-japan/issues/new?template=lab.yml) や [Issue（掲載の取り下げ）](https://github.com/Tomikent/marine-microbe-labs-japan/issues/new?template=remove.yml) からも送れます。

研究内容の説明文は、各研究室の公開情報をもとにAIが作成したものです。誤りがあれば上のフォームから教えてください。
掲載をやめてほしい研究室は、フォームで「掲載の取り下げ」を選んで送ってください。理由の記入は不要で、確認でき次第削除します。

## 直接編集する場合

1. `data/labs.json` に1件追加・修正（既存の項目をコピーして書き換え）
2. Pull Request を送る

`data/labs.js` と `data/labs.csv` は、main に入ると自動で作り直されます（入力漏れがあるとエラーになります）。
リンク切れは毎月1日に自動で確認し、見つかれば Issue に報告されます。
